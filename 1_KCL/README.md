# 1_KCL: Zoo Design Studio model (v0.3)
Open all 7 files in one Zoo project and run `main.kcl` to see the whole robot.
- parameters.kcl: every size lives here
- lib.kcl: shared shapes (blocks, rods, holes)
- base.kcl: base plate + motor clamp blocks
- drive.kcl: wheels, tires, motor straps, casters, reference motors
- body.kcl: bin, torso, back door
- so101.kcl: stand-in block for the SO-101 arm (import the real STL in the Zoo desktop app)

old_v0.2_unused/: the earlier home-made arm, claw and head. These aren't part of v0.3. If you want to open them, copy them next to parameters.kcl.
